# 🚀 FocusFlow – Student Productivity System

### 🎯 Plan Better. Study Smarter. Achieve More.

FocusFlow is a C++-based student productivity and study management application designed to help students organize academic tasks, manage deadlines, track study hours, and monitor their productivity through an interactive dashboard.

---

## ✨ Key Features

- 📌 **Task Management** – Create, view, search, and delete academic tasks.
- ⚡ **Priority Management** – Categorize tasks into High, Medium, and Low priorities.
- 📅 **Deadline Tracking** – Identify pending and overdue assignments.
- ⏱️ **Study Session Timer** – Track actual time spent studying.
- 📚 **Study Time Logging** – Associate study sessions with academic tasks.
- 🔍 **Task Search** – Find tasks using task names or subject codes.
- 📊 **Productivity Dashboard** – Monitor completed tasks, pending tasks, overdue tasks, and total study time.
- 💾 **Data Persistence** – Automatically save and load records using local files.

## ⚙️ Installation & Execution

**1. Clone the repository**

```bash
git clone https://github.com/shahitanishq25-cpu/FocusFlow-Student-Productivity-System.git
```

**2. Navigate to the project directory**

```bash
cd FocusFlow-Student-Productivity-System
```

**3. Compile the program**

```bash
g++ -std=c++11 main_monolith.cpp -o FocusFlow
```

**4. Run the application**

Windows:
```bash
FocusFlow.exe
```

Linux/macOS:
```bash
./FocusFlow
```
